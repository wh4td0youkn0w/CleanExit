# Clean Exit — 자리를 뜨기 전에, 흔적 없이.

공용 PC(복컴·교실)의 크롬에 남은 로그인 흔적을 검사하고, 버튼 한 번으로 정리하는 윈도우용 데스크톱 프로그램입니다.
화면 오른쪽 아래의 마스코트 **'싹'** 이 항상 떠 있으면서 지금 상태를 표정으로 알려 줍니다.

---

## 1. 기능 (프로젝트 개요의 해결 아이디어와 같은 순서)

| 기능 | 내용 |
|---|---|
| ① 로그인 흔적 감지 | 구글·네이버·카카오 등의 로그인 쿠키, 크롬 계정 연결, 저장된 비밀번호를 검사. 30초마다 자동으로 다시 검사 |
| ② 원클릭 정리 | [Clean Exit] 한 번으로 크롬 종료 → 쿠키·비밀번호·방문 기록·탭 기록 등 정리. [미리 보기]로 지울 목록 확인 가능 |
| ③ 종료 시 경고 | 자리 비움(기본 5분) 감지 시 알림, PC를 끌 때 자동 정리, 프로그램을 끌 때 흔적이 있으면 확인 |
| 마스코트 '싹' | 기본·흔적 발견·확인 중·크롬 사용 중·정리 중·정리 완료 6가지 표정. 누르면 창 열기, 끌어서 이동, 오른쪽 클릭 메뉴 |
| 사용 기록 | 기대 효과 확인용 통계를 개인정보 없이 CSV로 저장 |

## 2. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `main.py` | 프로그램 본체. **이 파일을 실행합니다.** |
| `config.py` | 검사할 사이트, 정리 항목, 기본값 (여기만 고치면 동작을 바꿀 수 있음) |
| `scanner.py` | ① 로그인 흔적 검사 |
| `cleaner.py` | ② 크롬 종료와 파일 정리 |
| `winapi.py` | ③ 자리 비움 감지, PC 종료 처리 (윈도우 API) |
| `mascot.py` | 마스코트 '싹' 그리기, 화면 위 오버레이, 경고 알림 |
| `stats.py` | 사용 기록(CSV) 저장 |
| `ssak.ico` | 프로그램 아이콘 |
| `tests/test_core.py` | 가짜 크롬 폴더로 검사·정리·기록 기능을 확인하는 자동 테스트 |
| `run.bat` / `run_test.bat` / `build_exe.bat` | 더블클릭 실행용 |

## 3. 준비 (처음 한 번만)

1. https://www.python.org/downloads/ 에서 Python 3.10 이상을 설치합니다.
   - 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 추가로 설치할 라이브러리는 없습니다. (tkinter, sqlite3, ctypes 모두 Python에 기본 포함)

## 4. 안전하게 테스트하기 ⭐ 먼저 이것부터

정리 기능은 실제로 파일을 지우므로, **처음에는 내 크롬이 아닌 테스트용 크롬으로** 시험하세요.

1. 테스트용 크롬 열기: `Win + R` → 아래를 붙여 넣고 Enter
   ```
   chrome.exe --user-data-dir="C:\CleanExitTest"
   ```
   → 아무 설정 없는 새 크롬이 열립니다. 여기서 네이버·구글 등에 로그인해 보세요.
2. 그 크롬 창을 **닫습니다.** (켜져 있으면 파일이 잠겨 '크롬 사용 중'으로 나옴)
3. `run_test.bat`을 더블클릭합니다.
   → 창이 열리고, 오른쪽 아래에 싹이 "로그인 흔적 ○개 발견!"이라고 말하면 성공
4. **[미리 보기]** → 지워질 목록 확인 → **[Clean Exit]** → 싹이 빗자루질 후 손을 흔들면 성공
5. 창의 X를 눌러도 싹은 남아 있습니다. 싹을 누르면 창이 다시 열리고, 싹을 오른쪽 클릭 → [Clean Exit 끄기]로 완전히 끕니다.

> 테스트 모드에서는 다운로드 폴더·최근 파일 정리가 자동으로 꺼집니다.
> 단, [Clean Exit]은 켜져 있는 **모든 크롬 창**을 닫으니 내 크롬에서 작업 중인 게 있으면 저장하고 누르세요.

자동 테스트(코드가 제대로 동작하는지 확인):
```
python -m unittest discover tests
```

## 5. 실제로 실행하기

- `run.bat` 더블클릭 (검은 창 없이 실행)
- 창 없이 싹만 띄우고 시작: `pythonw main.py --background`

**윈도우를 켤 때 자동 실행하기**
1. `Win + R` → `shell:startup` → Enter (시작프로그램 폴더가 열림)
2. 그 폴더에 `CleanExit.exe`의 바로 가기를 만들고, 바로 가기 속성의 '대상' 끝에 ` --background`를 붙입니다.

## 6. exe 파일로 만들기

`build_exe.bat`을 더블클릭하거나:
```
pip install pyinstaller
pyinstaller --onefile --windowed --name CleanExit --icon ssak.ico --add-data "ssak.ico;." main.py
```
→ `dist\CleanExit.exe`가 생깁니다. 이 파일 하나만 다른 PC에 복사하면 됩니다.

> 서명되지 않은 exe가 크롬을 종료하고 파일을 지우기 때문에 백신이 경고할 수 있습니다.
> 학교 PC에 설치할 때는 정보 선생님께 미리 허락을 받으세요.

## 7. 사용 기록(통계) — 기대 효과 확인용

- 위치: `C:\Users\(사용자)\AppData\Local\CleanExit\usage_log.csv` (창 아래 [사용 기록 폴더 열기])
- 엑셀·구글 시트로 바로 열 수 있습니다.
- **계정 이름, 이메일, 사이트 주소, 파일 이름은 기록하지 않습니다.** 숫자(흔적 유무, 사이트 개수)만 남깁니다.

| 이벤트 | 언제 기록되나 | 기대 효과에서 쓰는 법 |
|---|---|---|
| 정기_기록 | 5분마다 | `흔적_있음` 평균 = 흔적이 남아 있던 시간 비율 |
| 자리비움_경고 / 경고_응답 | 알림을 띄울 때 / 버튼을 눌렀을 때 | 경고 후 실제로 정리한 비율 |
| 정리 | 정리할 때 (`비고`에 계기: 버튼·알림·PC 종료 등) | 정리 횟수, 계기별 비율 |
| 검사 / 상태_변화 | 직접 검사할 때 / 상태가 바뀔 때 | 흔적이 생기고 사라진 시점 |

## 8. 작동 원리 (발표 대비)

**① 검사: 개인정보를 읽지 않는 설계**
- 크롬은 로그인 상태를 `쿠키`로 기억합니다. 쿠키는 프로필 폴더의 `Network\Cookies` 파일(SQLite DB)에 저장됩니다.
- 사이트마다 로그인했을 때만 생기는 쿠키가 있습니다. 예: 네이버 `NID_AUT`, 구글 `SID`
- DB에서 **사이트 주소와 쿠키 이름만** 읽습니다 (`SELECT host_key, name FROM cookies`). 쿠키 값(실제 비밀 정보)은 읽지 않습니다.
- 저장된 비밀번호와 크롬 계정 토큰은 `COUNT(*)`로 **개수만** 셉니다.
- 원본 DB를 직접 열지 않고 임시 폴더에 복사해서 읽기 전용으로 엽니다.

**② 정리: 두 번 확인하는 안전장치**
- 크롬이 켜져 있으면 윈도우가 파일을 잠그므로 먼저 크롬을 종료합니다 (정상 종료 요청 → 안 되면 강제 종료).
- '정리 계획'을 먼저 만들고([미리 보기]로 확인 가능) 그 계획대로만 지웁니다.
- 지우기 직전에 대상이 허용된 폴더 안에 있는지 다시 확인합니다. 허용 범위 밖의 파일은 절대 지우지 않습니다.

**③ 종료 시 경고**
- 자리 비움: 윈도우 API `GetLastInputInfo`로 마지막 입력 이후 시간을 계산합니다.
- PC 종료: 윈도우가 종료 직전에 보내는 신호(`WM_QUERYENDSESSION`)를 tkinter가 `WM_SAVE_YOURSELF`로 전달하면, `ShutdownBlockReasonCreate`로 종료 화면에 "로그인 흔적을 정리하고 있어요"를 띄우고 정리를 마칩니다.

**마스코트 '싹'**
- 그림 파일 없이 원·선·다각형을 tkinter Canvas에 코드로 그립니다. 그래서 크기를 바꿔도 깨지지 않습니다.
- 솜뭉치 몸통은 원 8개를 겹친 모양입니다. 테두리 색의 큰 원을 먼저 그리고 그 위에 몸통 색 원을 겹쳐서, 바깥 테두리만 남게 합니다.
- 제목 표시줄 없는 창(`overrideredirect`) + 특정 색을 투명하게 만드는 설정(`-transparentcolor`)으로 캐릭터만 화면에 떠 있게 합니다.
- 초당 15번 다시 그리면서 숨쉬기(위아래 흔들림), 눈 깜빡임, 빗자루질, 손 흔들기를 표현합니다.

## 9. 알려진 한계 (보고서의 '한계 및 개선점'에 활용)

- **크롬이 켜져 있으면 정확히 검사할 수 없습니다.** 윈도우가 쿠키 파일을 잠그기 때문입니다. 이때는 '크롬 사용 중'으로 표시하고, 자리 비움 알림은 그대로 띄웁니다.
- **쿠키 이름은 사이트가 바꿀 수 있습니다.** 바뀌면 `config.py`의 목록을 갱신해야 합니다.
- **크롬만 지원합니다.** 엣지도 구조가 거의 같아서 폴더 경로만 추가하면 확장할 수 있습니다.
- **PC 종료 시 정리는 실제 학교 PC에서 꼭 시험해 봐야 합니다.** 전원 버튼을 길게 눌러 강제로 끄는 경우나, 학교 PC 관리 프로그램이 종료를 대신 처리하는 경우에는 동작하지 않을 수 있습니다.
